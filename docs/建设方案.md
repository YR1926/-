# v0.3 建设方案

2026-10-19。默认收拢到数学、机器学习和深度学习，把强化学习与科研方向独立为第三轮。

## ★★★★★ 内容结构

前两轮36篇主线正文：数学8、ML11、DL/PyTorch9、CNN8。新增填充、通道、池化、增强、小CNN、残差和迁移7篇，形成从数学到可训练CNN的入门路径。第三轮保留26节点，其中强化学习8篇正文、其他18个框架。全库44篇正文，88题，仍待教师审核，不代表覆盖整个学科。

mainPath是默认主线，round是轮次，starterPath仍存全部可学正文以兼容维护数据。主线必须全有正文、满足先修顺序，前轮不得依赖后轮。稳定ID与旧进度继续保留。

## ★★★★★ 可维护实现

Markdown、JSON结构、来源与脚本是源；构建统一生成网页快照、索引与全文导出。每个知识点/导出/搜索结果标轮次。先修和相关关系不删除，仅在图谱中按轮次筛选，正文仍能跨轮跳转。

默认二维年表：从左向右，上下交错，含阶段跳转、下一课、进度状态与可点击正文。主轴代表学习顺序，不代表历史年代或完整先修图。第三轮虚线框架明确显示正文待编写。

三维使用Canvas透视投影的知识卡；卡片有标记、标题、状态，保留旋转、缩放、暂停、关系高亮与选择框。桌面扩大画布，窄屏分组换行。不是力导向物理模拟；重叠时可复位或筛阶段，完整标题见详情。大小/深浅只表示远近。

增加cnn_basics.py完整小CNN训练/验证/测试，附残差与冻结检查。未宣称完整ResNet或预训练迁移。主线5个交互、第三轮2个交互。所有运行均本地，无CDN或模型接口。
