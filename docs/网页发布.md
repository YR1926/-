# 网页访问与发布

## ★★★★★ 在线入口

学习网址：https://yr1926.github.io/-/ 。网页托管在 GitHub Pages，由 main 分支根目录发布，使用与本地目录版相同的 index.html 和 site/ 资源。手机浏览器可以直接访问，不需要接收 HTML 或解压文件。

这是联网入口，当前没有 Service Worker 离线缓存；断网使用请在电脑上保存单文件版“看见智能.html”。可以通过手机浏览器的收藏或添加到主屏幕保存入口；具体菜单由浏览器决定。

## ★★★★★ 个人记录

进度与笔记继续只存在使用者当前浏览器的本地存储，不上传 GitHub，也不会自动同步到其他设备。原本 file:// 页面和新的 https:// 网址使用不同存储；请在旧页面导出 JSON，再在网页中导入。清理浏览器数据、更换设备前请保留备份。

## ★★★★ 维护发布

修改源文件后先执行 tools/standalone.py（内部包含 build.py 与 validate.py），按改动范围验收。提交并推送到 main 后，GitHub Pages 会重新构建网页。根目录 .nojekyll 让静态资源直接发布；不要将个人文件或凭据加入仓库。

仓库 Settings → Pages 中选择“Deploy from a branch”，来源 main、路径 / (root)。首次启用与发布状态通过 GitHub Pages API 核查；浏览器实际访问成功才算上线成功，单纯推送成功不代表部署成功。

网页和便携版共用课程源文件、稳定知识点 ID 和记录格式。正文仍为待教师审核草稿，运行 PyTorch 脚本仍需另行配置 Python 和 torch。
