# 知识网络 UI 修订验收

日期：2026-10-19。对应 ui/network-nodes 分支；课程版本继续为 v0.3.0，本记录不表示发布了新的课程版本或离线压缩包。

- ★★★★★ 三维网络移除矩形知识卡和规则行列，改用数学菱形、机器学习六边形、深度学习轨道节点、CNN叠层节点。概念符号与外置标题帮助辨认，曲线表示真实先修联系；选中时突出相邻与关联节点。
- ★★★★ 基础大小随当前图内先修连接数量变化，另有透视缩放与焦点放大；形状与颜色表示章节，不表示正文质量。虚线轮廓仍表示正文待编写。移动端大范围视图优先显示部分标签，筛选到小章节后显示更多标题，可点击或使用选择框查看完整名称。
- ★★★★★ 默认知识网络入口显示三维星群；显式 view=2d 仍显示从左到右、上下交错的学习年表。前两轮36课与第三轮26节点分别查看。
- ★★★★★ 构建与结构校验通过。Edge 155.0.4283.62、file://、离线上下文完成浏览器验收：实际节点点击、邻接选择、旋转/缩放/暂停、代码与正文打开、62节点导航、二维年表跳转与滚动、实验数值、笔记持久化、导出后新上下文导入、旧记录兼容、错误备份原子拒绝。
- ★★★★ 390/768px响应式流程无文档级横向溢出；已查看桌面默认网络、焦点网络、手机主线、单章节和选修截图。补充实测：实际节点双击打开函数正文、方向键旋转、减少动态效果模式画面保持静止、手动播放后画面变化均通过。新几何布局下的标签会按空间避让，旋转后可能重叠，可缩放、筛章节或选择节点查看。
- ★★★★★ 主流程零 JavaScript 页面错误、零外部 HTTP/HTTPS 请求。完整机器结果见 validation/network-ui-results.json，桌面预览见知识网络预览.png。未使用真实学习者记录；未重跑算法训练，因为本轮未改动课程或算法代码。

复现：配置 PLAYWRIGHT_MODULE、BROWSER_EXECUTABLE 后执行 node tools/browser_acceptance.cjs。维护说明见验证记录.md；该文件与旧发行包记录保留原始 v0.3 验证范围。
