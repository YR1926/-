# 单文件便携版

## ★★★★★ 学习者怎么打开

收到“看见智能.html”后直接双击，用 Edge 或 Chrome 打开即可。只传这一个文件，无需解压、安装 Python、联网或启动服务。不要从聊天软件的文本预览中阅读，应先保存到电脑，再用浏览器打开。

从 GitHub 获取时，在仓库根目录打开“看见智能.html”，点击文件页右上方的“Download raw file”按钮下载原始文件；不要把 GitHub 的代码预览网页另存为 HTML。默认完整源码 ZIP 仍面向需要维护与 Agent 文件访问的人。

三维网络、二维年表、44 篇正文、搜索、检查题和7个交互实验均包含在文件中；默认主线仍为36课，第三轮独立。外部参考资料打开时需要联网。正文仍为待教师审核草稿。

## ★★★★★ 换入口，先带走记录

在旧页面的“我的记录”导出 JSON，然后打开单文件版，在“我的记录”导入该 JSON。更换路径、文件名、浏览器或电脑时，都采用这个办法。浏览器对 file:// 本地存储的隔离策略存在差异，不依赖两个入口自动共享记录。

HTML 不携带个人笔记，发送文件给同学不会发送当前浏览器的学习记录。更新时用新版同名 HTML 替换旧版，并保留最近的 JSON 备份；复制 HTML 不能备份进度。

## ★★★★ 代码与 Agent

知识点的“下载完整脚本”从内嵌代码生成 .py 文件，Markdown 源文件也直接下载。实践指南可以下载全部6个实现；第三轮 DQN 和策略脚本需要同时下载 q_learning.py 并放在同一目录。浏览器不执行 PyTorch，需要在已安装 torch 的 Python 环境运行下载的脚本。

在“使用与维护”下载全部课程 Markdown，或在正文点击“导出当前知识点给 Agent”，再将资料提供给支持文件上传的产品。需要按目录精确检索和维护时，继续使用 Git 仓库的 Markdown、JSON 与 agent/reading-guide.md。

## ★★★★ 维护者怎么更新

修改 content/、curriculum.json 或 site/ 中的源文件后执行：

```text
python tools/standalone.py
```

脚本先运行 build.py、validate.py，再覆盖根目录的“看见智能.html”。不要手工修改便携 HTML；不要将个人记录嵌入发行文件。便携版只读取固定公开源文件，不读取浏览器、个人备份或私人目录。

便携版和目录版使用同一知识库 ID、节点 ID 及进度格式。此迭代增加发行入口，没有更改正文版本或进度结构。浏览器仍可能提示本地下载确认，请选择保存文件。

来源：本项目实现与使用流程，2026-10-19；浏览器兼容范围以本轮离线验收记录为准。
