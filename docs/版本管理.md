# Git 版本管理

## ★★★★★ 当前基线

从现有 v0.3.0 开始建立 Git 历史，默认分支为 main，标签 v0.3.0 对应本次保存的版本。CHANGELOG.md 保留早期版本的更新说明；没有将旧压缩包伪造为既有 Git 提交。

本仓库只包含 ai-cv-learning 项目，不包含上级目录的其他项目、模型、虚拟环境或发行包。正文、结构源、网页快照、示例和公开验证记录均纳入版本管理，以便克隆后直接打开 index.html。

## ★★★★★ 日常保存与同步

在项目目录运行：

```text
git status
git diff
python tools/build.py
python tools/validate.py
python tools/standalone.py
git add <本次修改的文件>
git diff --cached
git commit -m "说明本次变更"
git push
```

首次远程同步需配置实际仓库地址及登录权限；未配置前，本地提交和标签已可使用。第一次推送主分支使用 `git push -u origin main`，版本标签单独使用 `git push origin v0.3.0`。协作前先提交自己的修改，再运行 `git pull --ff-only`；遇到分歧时先检查双方历史，不使用强制推送覆盖他人提交。

## ★★★★ 查看历史与恢复

```text
git log --oneline --decorate
git show v0.3.0:README.md
git diff v0.3.0 -- content/ site/
```

已推送的错误修改优先用 `git revert <提交号>` 生成撤销提交，保留协作历史。新版本在验证后更新 CHANGELOG.md，并创建新的标签；不要移动已共享的版本标签。

## ★★★★★ 个人记录

浏览器学习进度不在 Git 中，仍通过网页右上角“我的记录”导出、导入。默认名称的学习记录备份、personal/、private/ 和常见凭据文件已加入忽略规则。任意命名的私人文件仍需自行放入 personal/ 或 private/，提交前检查暂存区。

来源：本项目 Git 配置与维护约定；通用 Git 操作说明基于模型自身知识，2026-10-19。

## ★★★★ 便携版同步

根目录“看见智能.html”为生成产物，随源码提交，方便学习者直接下载原始文件使用。修改正文或网页后运行 tools/standalone.py，核对 git diff，再和源文件一同提交。不要手工改便携 HTML；不要把浏览器中的私人记录加入 Git。
