# v0.3 学习入口

## ★★★★★ 推荐学习顺序

第一轮19课：先补向量、点积、函数、导数、概率、矩阵乘法、链式法则与统计，再学数据划分、回归、损失、优化、指标、过拟合、kNN、树模型、分类、聚类与PCA。

第二轮17课：学习神经元、张量、反向传播、MLP、Softmax、优化器、数据批次、完整训练与归一化，然后学习卷积、步长/填充、通道、池化、增强、小CNN、残差与迁移。

默认已掌握Python。第三轮的强化学习、视觉专题、现代模型和科研实践属于选修方向，可稍后单独打开；不会混入36课主线完成率。每课先读算例、尝试预测，再运行实验/代码、做检查题并记录疑问。

## ★★★★★ 年表与知识卡

“知识网络”默认显示二维学习年表：从左向右，上下交错排章节。横向滚动、左右按钮或章节跳转可浏览，点卡片阅读；“定位下一课”找到当前范围第一篇尚未通过的正文。

“三维知识卡”可拖动旋转、滚轮缩放、点卡聚焦、双击阅读。右侧或下方选择框可定位完整标题。方向键旋转，空格暂停，+/-缩放。系统减少动态效果时默认暂停；窄屏按分组换行，仍可筛选单阶段阅读。

三维是Canvas上的透视投影，无需WebGL。连线表示先修，焦点虚线表示相关知识。二维轴只表示学习顺序。轮次切换后只显示所选范围，跨轮次联系可在正文先修/关联链接查看。

实线卡有正文；虚线卡是待编写框架，不等于不用学。“未开始”是个人进度，不等于内容缺失；前两轮36课目前全部有正文。

## ★★★★★ 代码实践

浏览器不执行PyTorch。页面代码面板可展开、下载脚本；建议使用完整发行目录，在examples目录运行。

```text
python torch_ml.py --task all
python torch_foundations.py
python cnn_basics.py --seed 7
```

按 [PyTorch安装选择器](https://pytorch.org/get-started/locally/) 选择系统和CPU配置。首次安装需联网，脚本本身不下载数据。实际验证环境为Python 3.13.7、torch 2.12.0+cpu。其他环境可能有数值差异。

CNN为合成横竖线小任务，不是实际照片识别评估。残差和冻结仅为局部机制检查。第三轮DQN/策略脚本另见实践指南。

## ★★★★★ 学习记录

阅读页面记录学习中，阅读确认记录已阅读，两题正确记录练习通过；通过不代表已经掌握。右上角“我的记录”导出进度与笔记，换电脑或浏览器前备份。旧Python记录继续保留在导出中，但不计主线进度。
