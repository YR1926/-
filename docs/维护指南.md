# 内容维护与迁移

## ★★★★★ 唯一事实来源

正文是 content/*.md；结构是 curriculum.json；来源是 sources/registry.json。网页 data.js、catalog.json 和 export/ 全部可重建。维护时不要只修改网页快照。

当前版 Markdown 渲染器刻意支持基础子集：标题、段落、无序列表、粗体、行内代码、代码块和 HTTPS 链接。暂不支持 Markdown 表格、LaTeX 排版、原始 HTML 或自定义组件。正文中的公式使用可直接阅读的 Unicode/文本表达。拓展语法时，先更新构建器与验证，再修改内容。

## ★★★★★ 新增知识点

- ★★★★★ 复制 templates/knowledge-point.md，填写真正完整的正文，而不是只留一句定义。
- ★★★★★ 在 curriculum.json 添加稳定 id、title、stage、round、summary、prerequisites、related、sources、tags、objectives、path、version、reviewStatus、minutes 与两道 quiz。可直接参考现有节点。
- ★★★★★ quiz 的 answer 是 options 的从 0 开始的下标，explanation 必须解释原因。不要只给选项编号。
- ★★★★★ sources 引用来源登记 ID；来源登记提供标题、URL、发布时间信息、查阅日期和相关章节。来源页面更新不等于某个结论首次发布时间。
- ★★★★ 构建后运行校验，检查无环先修、有效 ID、完整来源和快照一致性。在浏览器中检查正文与代码显示。

## ★★★★★ 版本与审核

修改实质正文或题目时增加 version，保持 ID 不变。若拆分或合并 ID，应另写迁移规则并保留映射，不能静默覆盖学生的历史记录。

reviewStatus 当前为 draft 或 outline。教师审核后若要增加 reviewed 状态，需要同时扩展校验器和页面状态文案；必须记录审核者、时间和审核范围，不能单改一处让页面虚假显示已审核。

## ★★★★ 本地重建与分发

```text
python tools/build.py
python tools/validate.py
python tools/package.py
```

package.py 会重新构建和校验，生成同级 releases/ 下的 ZIP 及 SHA-256 文件。首次发给新生前，解压到新目录并断网双击验证。压缩包使用显式白名单目录，不包含浏览器缓存、个人进度、临时测试文件或上层科研知识库。

## ★★★★ 可选本地服务

若浏览器策略阻止 file:// 页面，可运行 `python tools/serve.py`。服务只绑定 127.0.0.1，自动选空闲端口并打开浏览器。关闭终端即停止；这不是局域网共享服务。

端口变化会产生不同浏览器存储来源。切换 file:// 与本地服务前也应导出进度，再导入新来源。

## ★★★★ 后续架构选项

内容可迁移到 Quartz、其他静态站点生成器或文档工具；迁移时保留稳定 ID、相对链接和元数据。若做多人共享与老师查看班级进度，需要新增身份、授权、同步与隐私设计，不应把浏览器 localStorage 当成多人数据库。

若加语义检索，保留段落 ID 与来源定位。若加内置聊天，把模型接口作为可选适配层，避免反向绑死知识文件。若加入第三方图片、代码或模型，单独记录许可证和归属；“网上能看”不等于“可以打包再分发”。

## ★★★★★ v0.2 实现扩展

代码面板从examples脚本构建，修改脚本后须重新build。移除课程ID写入retiredIds，不复用旧ID；进度导出继续保留退休记录。新增实验在site/experiments-v2.js注册，三维投影在site/graph3d.js。课程、图谱与完成率的计数应由数据计算。

## ★★★★★ v0.3 分轮规则

round取1/2/3。mainPath应精确包含round<3的节点，全部有正文且满足先修顺序。前轮不能依赖后轮；related可跨轮次。starterPath保留全部正文的先修顺序，learningPaths维护可选路线。新增正文时同步这些字段后build/validate。

前两轮完成率只用mainPath，第三轮单独计数。空心/虚线只代表缺正文，不代表未学习；正文存在性与个人状态分别处理。年表在site/app.js和site/chronicle.css，三维卡在site/graph3d.js。修改实现后执行tools/browser_acceptance.cjs，并检查真实截图。
