# 标量、向量与矩阵：给数据一个形状

## 你会解决什么问题

★★★★★ “图片是数据”到底是什么意思？我们要先知道数据由多少个数构成，以及这些数怎样排列。一个数是标量，一列按顺序排列的数可以表示向量，按行列排列的数可以表示矩阵。

## 从一个数到一张小图片

★★★★ 0.7 可以表示一个分数，是标量。[2, 5, 1] 可以表示一个三维向量，有三个分量。这里的“三维”表示三个数值坐标，不一定指现实世界的三维空间。

```python
image = [
    [0, 128, 255],
    [64, 128, 192],
]
print(len(image))     # 2 行
print(len(image[0]))  # 3 列
print(image[1][0])    # 第 2 行第 1 列：64
```

★★★★★ 这张单通道灰度图形状是 (2, 3)，约定先高后宽。0 表示黑，255 表示白，中间值表示不同亮度。这是常见 8 位图像表示，并非所有图像数据都用 0～255。

## 向量运算先逐项理解

★★★★ 两个长度相同的向量可逐项相加：[1, 2] + [3, 4] 在数学中得到 [4, 6]。乘以标量 2，得到 [2, 4]。但 Python 列表里的加号会连接列表，不做这种逐项加法。

```python
a = [1, 2]
b = [3, 4]
result = [a[0] + b[0], a[1] + b[1]]
print(result)  # [4, 6]
```

## 形状是计算的约束

★★★★★ 彩色图片可用高 H、宽 W、通道 C 三个轴组织，例如 (4, 5, 3)。深度学习还常把多张图片组成批次，使用 (N, C, H, W) 或 (N, H, W, C)。两种顺序都可能出现，必须看框架约定，不能只看四个数字猜含义。

## 常见误区

- ★★★★★ 张量的轴数与每个轴的长度不同；形状 (2, 3) 是二维结构，共有 6 个数。
- ★★★★ 同样有 6 个数的 (2, 3) 和 (3, 2) 结构不同；交换轴也不等同于随便重新排列。
- ★★★★ 本课只建立形状直觉；矩阵乘法有单独的匹配规则，后续再学。

## 与计算机视觉的联系

★★★★★ 大量模型错误来自输入通道数或形状不匹配。养成在数据进入模型前检查形状的习惯，是从初学者走向可靠实验的第一步。

# 点积：把多个线索合成一个分数

## 你会解决什么问题

★★★★★ 一张图片可能有“偏红程度”“边缘强度”“纹理密度”等多个特征。怎样把多个线索合成一个分数？最简单的办法是给每个特征一个权重，再把贡献加起来。

## 一次完整计算

★★★★ 设输入 x = [1, 2, 3]，权重 w = [2, -1, 0.5]。点积写成 w·x，计算为 2×1 + (-1)×2 + 0.5×3 = 1.5。

正权重使正输入提高分数，负权重使它降低分数，零权重忽略该分量；这只是当前线性计算中的贡献，不能直接推成因果解释。

```python
x = [1, 2, 3]
w = [2, -1, 0.5]
assert len(x) == len(w)
score = 0
for i in range(len(x)):
    score = score + x[i] * w[i]
print(score)  # 1.5
```

★★★★ `range(3)` 依次给出 0、1、2。使用这些下标，就能取得两个列表对应位置的数。

## 用交互实验检查直觉

★★★★★ 改动本页演示中的三个权重。先预测哪个分量会让总分上升，再观察每一项的贡献。把第二个权重从 -1 改成 1，总分会增加 4，因为第二个输入是 2，权重变化是 2。

## 点积也与几何有关

★★★ 非零向量的点积等于“两个向量长度的乘积 × 夹角的余弦”。因此它同时受方向和长度影响。把向量归一化后再比较方向，是后续学习相似度和注意力的桥梁；零向量的余弦相似度需要特殊处理。

## 常见误区

- ★★★★★ 逐项乘法得到多个数，点积最终得到一个数。
- ★★★★ 两个向量必须具有相同分量数量；不能静默丢掉多余分量。
- ★★★★ 加权分数不是概率，它可以为负，也可以大于 1。

## 与计算机视觉的联系

★★★★ 线性分类器、神经元、卷积局部计算与注意力相似度都能看到点积。先理解这一种操作，后续许多网络结构就不再像完全不同的公式。

# 函数与坐标：看懂输入如何变成输出

## 你会解决什么问题

★★★★★ 模型“输入一张图片，输出一个结果”听上去抽象。先看一个最小数学函数：y = 2x + 1。给定一个允许的输入 x，它按明确规则得到一个输出 y。

## 把关系画在坐标上

★★★★ x 取 0、1、2 时，y 分别是 1、3、5。把 (0, 1)、(1, 3)、(2, 5) 标在平面坐标系中，可以看到它们落在一条直线上。横轴描述 x，纵轴描述 y。

```python
def f(x):
    return 2 * x + 1

for x in [0, 1, 2]:
    print(x, f(x))
```

## 斜率和截距控制什么

★★★★★ 推广到 y = wx + b。w 是斜率：x 增加 1，y 增加 w。b 是截距：x = 0 时，y = b。w = 0 时得到水平直线；w 为负时，随着 x 增大，y 下降。

在一次预测中，w 和 b 固定；学习过程则调整 w 和 b，让这条线更符合数据。区分“改变输入观察预测”和“改变参数学习规则”非常重要。

## 不止直线

★★★★ y = x² 是曲线，x 从 1 增加到 2，y 增加 3；x 从 2 增加到 3，y 增加 5。相同输入增量不再对应相同输出增量。这引出下一课的变化率和导数。

请写出 y = -x + 2 在 x = 0、1、2 时的三个点，再解释为什么斜率为负。预期输出分别是 2、1、0。

## 常见误区

- ★★★★★ 一张图的横轴可能是输入、训练轮次或参数；看到一条曲线前先读坐标轴。
- ★★★★ 数学函数的每个输入只能对应一个输出；不同输入可以得到同一个输出。
- ★★★★ 数学中常把含偏置的 wx + b 称为仿射函数；机器学习里常将这类预测统称线性模型，注意语境。

## 与计算机视觉的联系

★★★★ 视觉模型是高维输入到输出的函数。图像有很多像素，输出可能是类别分数或检测框，但输入、参数和输出的区别保持不变。

# 导数：衡量一个地方变得有多快

## 你会解决什么问题

★★★★★ 训练模型时，我们需要知道参数往哪个方向轻微变化，会让误差下降。导数描述函数在一个位置附近的变化率，是回答这个问题的工具。

## 先看平均变化率

★★★★ 从 x 到 x + h，输出从 f(x) 变到 f(x+h)。平均变化率为 (f(x+h) - f(x)) / h，其中 h 不为 0。它对应两个点连线的斜率。

设 f(x)=x²，x=2，h=0.1，则平均变化率为 (2.1² - 2²)/0.1 = 4.1。当 h 更接近 0，差商越来越接近 4。

## 从差商走到导数

★★★★★ 对 x² 展开：( (x+h)² - x² ) / h = 2x + h。让 h 趋近于 0，得到 f′(x)=2x。这里说的是极限，不是直接把 h=0 填进原来的分式。

```python
def f(x):
    return x * x

x = 2.0
h = 0.001
estimate = (f(x + h) - f(x)) / h
print(round(estimate, 3))  # 4.001
```

★★★★ 本页切线演示用准确公式 2x 绘图，代码展示的是有限差分近似。计算机上 h 不是越小越好：过小会使相近数相减的舍入误差明显。

## 导数能告诉你什么

★★★★★ 正导数：在足够小的邻域内，增加 x 通常使函数值增加；负导数则相反。绝对值大，表示局部更陡。导数描述局部，不保证大步移动仍遵循同样趋势。

当函数有多个输入时，可先只改变其中一个输入，得到偏导数。把各参数的偏导数排列起来，就是梯度。后续的反向传播用链式法则高效计算这些量。

## 常见误区

- ★★★★★ 导数为 0 不保证是最小值；也不保证模型已经学好。
- ★★★★ 函数值大与导数大没有必然联系；水平线 y=100 的导数是 0。
- ★★★★ 某些函数在特定点不可导，例如绝对值函数在 0 处；实际框架会有相应约定。

## 与计算机视觉的联系

★★★★ 深度网络有很多参数。我们不需要逐个凭感觉尝试，而是借助梯度判断哪些小变化可能降低训练损失；这一结论依然受步长和函数局部性质限制。

# 均值与概率：描述数据中的不确定性

## 你会解决什么问题

★★★★★ 学习算法面对的是有限样本。我们既要描述手头的数据，也要承认未观察数据的不确定性。先掌握平均值、频率和概率的区别。

## 平均值是怎样得到的

★★★★ 三次测量为 2、4、6，平均值为 (2+4+6)/3=4。平均值把一组数据压缩成一个数，会丢失分布信息：[4,4,4] 和 [0,4,8] 的平均值相同，波动却不同。

```python
values = [2, 4, 6]
mean = sum(values) / len(values)
variance = sum((value - mean) ** 2 for value in values) / len(values)
print(mean)                 # 4.0
print(round(variance, 3))   # 2.667
```

★★★ 上式用除以 n 的均方偏差描述当前这组数据，不是除以 n-1 的无偏样本方差估计。先弄清你在描述样本，还是估计总体。

## 频率不是永恒事实

★★★★★ 10 张图片中 3 张猫，样本频率是 0.3。概率是对事件发生不确定性的数学描述，取值在 0 与 1 之间。在合适的采样假设下，频率可用来估计概率；小样本或偏差采样会使估计不可靠。

如果只从宠物论坛收集图片，你得到的猫比例不能直接代表所有网络图片中的猫比例。样本来自哪里，常常比计算小数是否精确更重要。

## 期望的直觉

★★★★ 公平骰子的六个点数各有 1/6 概率，期望为 (1+2+3+4+5+6)/6=3.5。期望是按概率加权的平均结果，不保证一次观察能取到这个数。

## 常见误区

- ★★★★★ 一批数据上的频率，不自动代表另一批数据的规律。
- ★★★★ 模型输出 0.9 不保证类似样本真的有 90% 正确率；需要考察概率校准。
- ★★★★ 数据分布不平衡时，不能只看总体准确率，还要分析每类错误。

## 与计算机视觉的联系

★★★★★ 摄像头、光照、场景和类别比例变化，会让训练数据与实际使用环境不同。描述数据分布、分组评估和报告不确定性，是可信 CV 实验的基础。

# 矩阵乘法与批量线性变换

## 你会解决什么问题

★★★★★ 从一个点积推广到一批样本，检查每个轴的含义。

## 核心概念与计算

★★★★★ 若 X 形状为 (N,D)，W 为 (D,K)，则 XW 为 (N,K)。输出第 i 行第 j 列等于 X 的第 i 行与 W 的第 j 列的点积。内维 D 必须一致，输出保留 N 和 K。

★★★★ 神经网络的 nn.Linear(D,K) 将权重存为 (K,D)，计算 X @ weight.T + bias；不要把数学记号的存储方向和框架权重布局混用。矩阵乘法通常不交换，AB 与 BA 可能形状不同，甚至后者根本无法计算。

## 一次具体的推演

X=[[1,2],[3,4]]，W=[[1,0],[0,2]]，则 XW=[[1,4],[3,8]]。第二个特征被放大两倍。对 N=32、D=10、K=3，输出应为 (32,3)，权重数量为 30，加上偏置 3，共 33 个参数。

# 偏导数、梯度与链式法则

## 你会解决什么问题

★★★★★ 理解自动微分背后的局部导数传递。

## 核心概念与计算

★★★★★ 对 L(w,b)=(wx+b-y)²，求 w 的偏导时暂时固定 b、x、y。令 z=wx+b，e=z-y，则 ∂L/∂e=2e，∂e/∂z=1，∂z/∂w=x，连乘得到 ∂L/∂w=2ex；∂L/∂b=2e。

★★★★ 如果一个变量通过多条计算路径影响结果，各路径贡献需要相加。梯度是对所有可学习参数的偏导数组合；反向传播利用计算图复用中间结果，而不是给每个参数单独做数值试探。

## 一次具体的推演

取 x=2,w=1,b=0,y=3，预测为2，e=-1，损失为1。dw=-4，db=-2。学习率0.1时，同步更新得到 w=1.4,b=0.2；新预测3.0，损失0。这只是一条样本的巧合，并非一步训练必然成功。

★★★★ 先遮住答案复述上面的计算，再改变一个输入或超参数，写下预期结果。若结果不同，先检查公式、形状与数据划分，不只重复运行。

## 常见误区

- ★★★★★ 两个梯度都要用同一组旧参数计算。
- ★★★★ 目标变量如果不应被优化，应切断梯度；否则优化的已不是原来的目标。

## 与计算机视觉的联系

★★★★ 卷积、线性层与激活组合后，链式法则仍适用。共享权重会汇总多个位置的梯度。

## 你会解决什么问题

# 训练、验证与测试：给模型一次公平考试

## 你会解决什么问题

★★★★★ 一个模型记住练习题，可以在练习题上表现很好。我们真正关心的是未见样本。数据划分用于隔离模型学习、模型选择与最后评估。

## 三个子集各司其职

- ★★★★★ 训练集：用于拟合模型参数，以及只应从训练数据估计的预处理参数。
- ★★★★★ 验证集：用于比较模型、选择学习率、训练轮次等设置。
- ★★★★★ 测试集：在方案确定后用于最终评估，不应反复指导修改。

★★★★ 70%/15%/15% 是可能的比例，不是通用定律。样本少、类别稀有、时间序列或多中心数据，需要考虑交叉验证、分层或分组策略。

## 一段仅演示分组的代码

```python
samples = [
    {"id": "a1", "video": "A"},
    {"id": "a2", "video": "A"},
    {"id": "b1", "video": "B"},
]
train = [s for s in samples if s["video"] == "A"]
test = [s for s in samples if s["video"] == "B"]
print(len(train), len(test))  # 2 1
```

★★★★ 花括号构成字典，用键访问字段；方括号中的写法叫列表推导式，等价于遍历并筛选。本例太小且没有验证集，只用来展示“同一组不跨集合”的原则，不是可报告的实验设计。

## 泄漏比比例更危险

★★★★★ 相邻视频帧、同一人的多张照片、重复图片，如果跨训练和测试集合，会让测试过于容易。用全部数据计算归一化均值、先看测试标签再选特征，也可能泄漏。

正确做法是先按实际任务定义独立单位，再划分；在训练集拟合需要学习的预处理参数，然后固定这些参数处理验证和测试数据。允许使用未来信息还是只能看过去，也由任务决定。

- ★★★★★ 固定随机种子有助于复现，不会自动消除泄漏或采样偏差。
- ★★★★ 验证集调出来的最好分数也可能有选择偏差，不应当作最终独立证据。
- ★★★★ 训练集高分、测试集低分可能涉及过拟合或分布变化，不能只凭两个数字确定原因。

## 与计算机视觉的联系

★★★★★ 水下视频、医学图像和工业检测都容易出现同一场景或对象的相关样本。正确划分往往比更换一个网络模块更影响实验结论是否可信。

# 线性模型：让一条直线解释数据

## 你会解决什么问题

★★★★★ 手头有几组输入与目标，能否用一个简单规则概括？线性回归先假设预测形式是 y_hat = wx + b，再从数据中确定参数。

## 一个能手算的数据集

★★★★ 输入 x = [0,1,2,3]，目标 y = [1,3,5,7]。观察可猜到 w=2、b=1。这里数据刻意设计得很整齐，现实数据通常有噪声、遗漏因素或非线性。

```python
xs = [0, 1, 2, 3]
ys = [1, 3, 5, 7]
w, b = 2, 1
predictions = [w * x + b for x in xs]
print(predictions)  # [1, 3, 5, 7]
```

★★★★★ y 是目标，y_hat 是预测；即使这个样例里相等，也不能混用。学习过程调整 w 和 b，输入和标签则由数据提供。

## 多个输入特征怎么办

★★★★ 如果输入包含两个特征 x1、x2，可写成 y_hat = w1×x1 + w2×x2 + b，也就是 w·x + b。每个特征都有对应权重，但权重大小受特征量纲与相关性影响，不能直接当作“真实重要性”。

## 手动拟合的局限

★★★★★ 把 w=1、b=0 代入，预测变成 [0,1,2,3]。我们能看出不匹配，但要在大量参数之间自动比较，就需要损失函数；要自动调整参数，就需要优化算法。这是接下来两课的主线。

试着比较 w=2、b=0 与 w=1、b=1：前者每个点都少 1，后者误差随 x 增大。这个区别分别对应偏置和斜率的问题。

## 常见误区

- ★★★★★ 模型形式是假设，不是自然规律；数据弯曲时，直线可能表达不足。
- ★★★★ 训练范围内拟合好，不代表远离训练范围的外推可靠。
- ★★★★ 参数拟合体现相关性，不能仅凭一条回归线证明因果关系。

## 与计算机视觉的联系

★★★★ 视觉网络末端常有线性层，把提取好的特征变成类别分数或数值预测。理解线性模型能帮助你区分“特征提取部分”和“最后的预测头”。

# 损失函数：把预测错误变成可比较的数

## 你会解决什么问题

★★★★★ 优化算法需要一个能比较参数好坏的数。损失函数把预测与目标之间的差异转换成训练目标。不同任务和错误代价，适合的损失可能不同。

## 一步步得到均方误差

★★★★ 残差 e = y_hat - y。预测 [2,4]、目标 [1,2] 时，残差为 [1,2]。先平方得到 [1,4]，再求平均，得到 MSE = 2.5。

```python
def mse(predictions, targets):
    if len(predictions) != len(targets) or len(targets) == 0:
        raise ValueError("需要等长、非空的数据")
    total = 0
    for p, y in zip(predictions, targets):
        total = total + (p - y) ** 2
    return total / len(targets)

print(mse([2, 4], [1, 2]))  # 2.5
```

★★★★ `zip` 把对应位置的元素配成一对。本例先检查长度，因为 zip 默认在较短的序列耗尽时就结束，未检查会掩盖数据对齐错误。

## 为什么要平方

★★★★★ 带符号的误差会抵消；平方消除符号，并让大误差产生更大代价。例如误差从 1 变 2，平方代价从 1 变 4。代价也因此更容易受异常点影响。

有些教材把平方损失再乘 1/2，用于简化求导系数。本课使用不带 1/2 的 MSE，后续求导也保持同一个约定。

## 损失与指标

★★★★★ 损失用于驱动参数更新；指标用于回答任务关心的问题。分类常使用交叉熵训练，并报告准确率、召回率等；回归可以优化 MSE，同时查看绝对误差。训练损失和测试指标还来自不同数据子集，不能混为一谈。

## 常见误区

- ★★★★★ 不同数据尺度、不同损失定义下，数值大小不能直接横向比较。
- ★★★★ 训练损失为 0 不证明模型对新数据可靠，也可能只是记住了训练样本。
- ★★★★ 最小化一个代理目标，不保证同时优化所有实际需求，例如漏检代价或部署速度。

## 与计算机视觉的联系

★★★★ 检测网络可能同时包含类别损失与框位置损失；分割关注像素预测。每加一个损失项，都应该说清它约束什么、怎样加权、是否匹配评估目标。

# 梯度下降：让参数朝误差更小的方向走

## 你会解决什么问题

★★★★★ 我们已经能计算误差，也能知道某个参数附近误差怎样变化。梯度下降把二者连接起来：沿梯度相反方向，小步更新参数。

## 从一个参数看懂更新

★★★★★ 设 L(w)=(w-3)²，导数 g=2(w-3)。更新规则是 w_new = w - ηg，其中 η 是正的学习率。w=0、η=0.1 时，g=-6，下一步 w=0.6，损失从 9 降到 5.76。

```python
w = 0.0
learning_rate = 0.1
for step in range(20):
    gradient = 2 * (w - 3)
    w = w - learning_rate * gradient
print(round(w, 3))  # 2.965
```

## 为什么步长很重要

★★★★★ 在本例中，令误差 e=w-3，则 e_new=(1-2η)e。若 0<η<1，误差绝对值会逐步缩小；η=1 时振荡不衰减；η>1 时通常越走越远。一般神经网络没有这个统一阈值，不能把本例结论机械套到所有训练任务。

本页交互演示可单步、连续播放、修改学习率和重置。先试 0.1，再试 0.8、1.0、1.1，解释曲线和轨迹的变化。

## 训练一条真正依赖样本的直线

★★★★ 若预测 y_hat = wx+b，MSE 对 w 的导数是样本平均的 2×(y_hat-y)×x，对 b 的导数是样本平均的 2×(y_hat-y)。两者先用旧参数计算，再一起更新。

```python
xs, ys = [0, 1, 2, 3], [1, 3, 5, 7]
w, b, lr = 0.0, 0.0, 0.05
for step in range(1000):
    errors = [w * x + b - y for x, y in zip(xs, ys)]
    dw = 2 * sum(e * x for e, x in zip(errors, xs)) / len(xs)
    db = 2 * sum(errors) / len(xs)
    w = w - lr * dw
    b = b - lr * db
print(round(w, 3), round(b, 3))  # 2.0 1.0
```

## 常见误区

- ★★★★★ 反向传播计算梯度；优化器使用梯度更新参数。它们不是同一个步骤。
- ★★★★ 梯度下降不保证任意网络都达到全局最优；损失地形、初始化和优化设置都会影响结果。
- ★★★★ 本例使用全部样本计算梯度，属于全批量更新。真实训练常使用小批量样本。

## 与计算机视觉的联系

★★★★★ CNN 和 Transformer 的训练也遵循“前向预测—计算损失—求梯度—更新参数”的主线。参数数量变多，计算更复杂，但核心问题没有改变。

# 混淆矩阵、阈值与分类指标

## 你会解决什么问题

★★★★★ 依据漏检与误报代价选择指标，而不是只盯着准确率。

## 核心概念与计算

★★★★★ 指定正类后，TP是真正例、FP是假正例、FN是假负例、TN是真负例。Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2PR/(P+R)。分母为0时需要明确约定并报告，不应静默制造完美分数。

★★★★ 降低分数阈值通常增加被预测为正的样本，召回不会下降，但精确率不保证单调变化。ROC与PR曲线比较一系列阈值；类别稀少时PR常更直接体现误报负担。最终阈值应在验证集依据业务目标确定，再固定测试。

# 神经元与非线性：从直线走向网络

## 你会解决什么问题

★★★★★ 一条直线表达不了所有关系。神经网络将加权求和与非线性变换组合起来，让模型能够表示更复杂的函数。

## 最小神经元的三步

★★★★ 输入 x=[1,2]，权重 w=[2,-2]，偏置 b=1。先求点积得到 -2，再加偏置得到 -1，最后经过 ReLU，输出 max(0,-1)=0。

```python
def relu(value):
    return max(0, value)

def neuron(x, w, b):
    if len(x) != len(w):
        raise ValueError("输入与权重长度应一致")
    z = sum(a * weight for a, weight in zip(x, w)) + b
    return relu(z)

print(neuron([1, 2], [2, -2], 1))  # 0
```

## 为什么不能只堆直线

★★★★★ 假设第一层 h=a×x+b，第二层 y=c×h+d。代入后 y=(c×a)×x+(c×b+d)，仍然是关于 x 的一条直线。多维情况下，连续仿射层也可以合并成一个仿射变换。

加入 ReLU 这样的非线性后，组合函数的表达能力发生变化。多个神经元可以提取不同的中间特征，组成隐藏层。隐藏层的表示由训练过程形成，不保证每个神经元都对应一个人类概念。

## 从一个神经元到训练流程

★★★★ 多个神经元组成层，多层组成网络。训练时先计算预测和损失，再使用链式法则把梯度传回各参数，最后由优化器更新。后续的自动微分与反向传播章节会系统展开。

ReLU 在负区间输出 0，在正区间保留输入，0 处不可导；实现通常采用约定的梯度值。并非所有层都应该使用 ReLU，输出层要与任务和损失匹配。

## 常见误区

- ★★★★★ 人工神经元是数学计算单元，不应当作真实生物神经元的完整模拟。
- ★★★★ 更深、更宽不自动更好，还要考虑数据量、优化、泛化与算力。
- ★★★★ 神经元输出不天然是概率；ReLU 输出可以大于 1。

## 与计算机视觉的联系

★★★★ 卷积层也在进行局部加权求和，并常接非线性。先学会手算一个神经元，再看一整层卷积，就可以把复杂网络拆回可理解的计算。

# 自动微分与反向传播

## 你会解决什么问题

★★★★★ 连接计算图、叶子参数和梯度累积，正确完成一次更新。

## 核心概念与计算

★★★★★ 对需要求导的张量设置requires_grad，前向运算构建计算图，标量loss.backward()把导数累积到叶子张量的.grad。优化器.step()才根据梯度更新参数，两步不能混同。

★★★★ 多次backward默认累积梯度，因此常在新一轮更新前zero_grad。`torch.no_grad()`用于不需要构建计算图的推理和目标计算；`detach()`得到与原图断开的视图，但不保证复制底层存储。

## 一次具体的推演

```python
import torch
w = torch.tensor(1., requires_grad=True)
loss = (2 * w - 3) ** 2
loss.backward()
print(w.grad.item())  # -4.0
with torch.no_grad():
    w -= 0.1 * w.grad
print(round(w.item(), 2))  # 1.4
```

# Dropout、归一化与训练模式

# 卷积：用一个小窗口读懂图像

## 你会解决什么问题

★★★★★ 图像的局部邻域包含边缘和纹理。若每个像素位置都使用独立的大量权重，参数很多，也难利用局部结构。卷积层让小核在不同位置复用同一组权重。

## 一个窗口中的计算

★★★★ 取 3×3 图像区域与 3×3 核，对应位置相乘，再把 9 个乘积相加，得到一个输出值。核向右或向下移动，重复计算，输出值组成特征图。

若核的 9 个值都是 1/9，那么输出是该区域的平均值，可平滑局部变化。若核左右两侧权重符号相反，就可能对某种方向的亮度变化产生较强响应。响应的符号受核方向影响。

## 尺寸为什么变小

★★★★★ 在本页限定的单通道、步长 1、无填充条件下，5×5 输入与 3×3 核只允许 3×3 个有效位置。一般一维尺寸公式为 floor((输入 + 2×填充 - 有效核尺寸)/步长)+1；使用膨胀卷积时，有效核尺寸还需要另算。

```python
image = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
kernel = [[1/9, 1/9, 1/9], [1/9, 1/9, 1/9], [1/9, 1/9, 1/9]]
value = 0
for row in range(3):
    for col in range(3):
        value += image[row][col] * kernel[row][col]
print(round(value, 3))  # 5.0
```

## 观察本页实验

★★★★ 先选均值核，看每个窗口如何得到局部平均；再选边缘核，观察亮度分界处的响应。可以单步移动、播放或点击任意输入格修改数值。核是人为设定的教学示例，没有执行训练。

## 常见误区

- ★★★★★ 本页和多数框架使用不翻转核的互相关。严格数学卷积需要翻转核，但深度学习仍常沿用“卷积”名称。
- ★★★★ 一个核产生的响应不是语义识别结果。训练出来的多层表示才逐步形成任务相关特征。
- ★★★★ 多通道输入还要对通道求和，多输出通道需要多组核；本页暂不展示这些额外维度。
- ★★★★ 卷积的平移性质会受边界、步长和其他操作影响，不能笼统说整网对平移完全不变。

## 与计算机视觉的联系

★★★★★ 这是理解 CNN 的入口。下一步依次学习填充与步长、多通道、池化和感受野，再读 LeNet、ResNet 等结构，才能把结构图和实际张量运算对应起来。

# 步长、填充与输出尺寸

## 你会解决什么问题

★★★★★ 精确追踪特征图分辨率与边界处理。

## 核心概念与计算

卷积的小窗口如何在边缘移动？设输入高度为 H，核大小 K，两侧各补 P 个像素，步长 S，膨胀率 D。有效核宽度是 D(K−1)+1。输出高度 H_out=⌊(H+2P−D(K−1)−1)/S⌋+1，宽度同理。这里的⌊ ⌋表示向下取整，不能把小数维度交给下一层。

Padding保留边缘参与计算的机会；stride让窗口一次走几格；dilation在核元素间插空以扩大采样范围。零填充并不是新观测，边缘输出会受填充值影响。常见3×3、步长1、padding1保留空间尺寸，但增加步长后不能沿用这个结论。

## 一次具体的推演

输入7×7，K=3、P=1、S=2、D=1，则⌊(7+2−3)/2⌋+1=4，得到4×4。去掉填充则⌊(7−3)/2⌋+1=3。两种配置参数量相同，输出尺寸不同。

手画一条长度7的像素序列，左右各补1个零，标出窗口起点0、2、4、6。最后一个窗口正好覆盖填充后的末端。

## PyTorch 最小实现

```python
import torch
from torch import nn
x = torch.zeros(2, 3, 7, 7)
layer = nn.Conv2d(3, 8, 3, stride=2, padding=1)
assert layer(x).shape == (2, 8, 4, 4)
print(layer(x).shape)
```

# 多通道卷积与参数量

## 你会解决什么问题

★★★★★ 理解输入通道求和、输出通道和卷积权重形状。

## 核心概念与计算

RGB图像在PyTorch里通常用N×C×H×W表示。普通卷积的一个输出通道，会分别对所有输入通道卷积，再把结果相加并加一个偏置。不同输出通道各有一套核，可以提取不同特征。

普通Conv2d的权重形状为C_out×C_in×K_h×K_w；含偏置的参数量是C_out×C_in×K_h×K_w+C_out。groups=g时，每个输出通道只看C_in/g个输入通道，参数量改为C_out×(C_in/g)×K_h×K_w+C_out，输入和输出通道数都必须能被g整除。

## 一次具体的推演

3通道输入、8通道输出、3×3卷积：8×3×3×3+8=224个参数。batch从2变成32，参数仍为224，因为同一组权重用于所有样本和空间位置。1×1卷积也不是无操作：它能在每个位置混合通道，例如把64维特征投影成16维。

把groups设成输入通道数且输出通道数为其整数倍，就是逐通道卷积的一种配置，后面常接1×1卷积混合通道。

## PyTorch 最小实现

```python
import torch
from torch import nn
conv = nn.Conv2d(3, 8, 3)
assert sum(p.numel() for p in conv.parameters()) == 224
assert conv.weight.shape == (8, 3, 3, 3)

```

# 池化与感受野

## 你会解决什么问题

★★★★★ 理解下采样、信息损失和有效观察范围。

## 核心概念与计算

池化把局部区域汇总成较少的数。最大池化保留最大的响应；平均池化计算均值，二者通常没有可训练权重。池化会丢失位置信息，它能带来局部平移的稳健性，但不保证严格平移不变。

感受野是某个输出依赖的输入范围。初始化感受野r=1、采样间距j=1。对于核K、膨胀D、步长S的一层，更新r_new=r+(K−1)D×j，j_new=j×S。这里讨论的是理论感受野；实际梯度影响的大小可能很不均匀。

## 一次具体的推演

2×2区域[[1,3],[2,0]]，最大池化得3，平均池化得1.5。再看一条网络：3×3步长1卷积后r=3、j=1；2×2步长2池化后r=4、j=2；再做3×3步长1卷积，r=4+2×2=8，j仍为2。

全局平均池化把每个通道汇总为1个数。它减少全连接参数，但如果任务要求目标精确位置，过早汇总会丢失重要信息。

## PyTorch 最小实现

```python
import torch
from torch.nn import functional as F
x = torch.tensor([[[[1., 3.], [2., 0.]]]])
assert F.max_pool2d(x, 2).item() == 3
assert F.avg_pool2d(x, 2).item() == 1.5
print("max=3; mean=1.5")
```

# 残差连接与 ResNet

## 你会解决什么问题

★★★★★ 理解残差分支、维度匹配和深层网络优化。

## 核心概念与计算

普通块学习H(x)，残差块写成y=F(x)+x，让可学习分支近似“需要改多少”。对于含末尾激活的经典块，还要对相加结果施加ReLU，不能忽略这一步讨论负输入的恒等性。

逐元素相加要求形状匹配。若通道或空间尺寸不同，可用1×1卷积及相应步长把捷径投影到同一形状：y=F(x)+P(x)。拼接会增加通道，相加不会，它们是不同操作。残差路径有利于优化深网，但不能保证不发生梯度问题或过拟合。

## 一次具体的推演

取x=[2,−1]、F(x)=[0.5,0.2]，相加得[2.5,−0.8]；若末尾ReLU，输出为[2.5,0]。x为[N,8,16,16]而F(x)为[N,16,8,8]时，捷径可用Conv2d(8,16,1,stride=2)。

下面是无BatchNorm的最小残差示意。真实ResNet还涉及归一化、块的排列与初始化；不能把这个小块称作完整ResNet-18。

import torch

branch = nn.Sequential(nn.Conv2d(8, 16, 3, stride=2, padding=1),
    nn.ReLU(), nn.Conv2d(16, 16, 3, padding=1))
shortcut = nn.Conv2d(8, 16, 1, stride=2)
y = torch.relu(branch(x) + shortcut(x))
assert y.shape == (2, 16, 8, 8)

# 迁移学习与微调

## 你会解决什么问题

★★★★★ 设置冻结层、学习率与训练/验证协议。

## 核心概念与计算

迁移学习把源任务得到的表示用于新任务。冻结特征提取器时，只训练新的分类头；微调则允许部分或全部预训练参数更新，通常给已有层更小的学习率。数据少时先建立冻结基线，再根据验证结果考虑逐层解冻。

requires_grad=False禁止参数梯度，但不等于model.eval()。BatchNorm的运行统计是buffer，不因冻结参数自动停止更新；Dropout也仍受train/eval模式影响。冻结主干时通常让主干eval、分类头train；解冻后重新确认优化器包含需要更新的参数。

## 一次具体的推演

假设预训练主干输出512维，新任务有3类，则新Linear头含512×3+3=1539参数。主干冻结后这些参数仍参与前向，只是不参与参数更新。

下面代码演示冻结和梯度检查，主干随机初始化，刻意不下载权重，因此不能宣称得到了预训练迁移效果。真实迁移实验需要选定权重来源、对应预处理，并与从头训练的公平基线比较。

## PyTorch 最小实现

```python
import torch
from torch import nn
backbone = nn.Sequential(nn.Linear(4, 8), nn.ReLU())
for p in backbone.parameters():
    p.requires_grad_(False)
head = nn.Linear(8, 3)
backbone.eval(); head.train()
loss = nn.functional.cross_entropy(head(backbone(torch.randn(5, 4))),
    torch.tensor([0, 1, 2, 0, 1]))
loss.backward()
assert all(p.grad is None for p in backbone.parameters())
assert head.weight.grad is not None
print("Frozen backbone; head receives gradients.")
```
