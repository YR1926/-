# 通用 Agent 阅读指南

## ★★★★★ 读什么

先读 README.md 确认范围，再读 catalog.json 取得节点 ID、路径、先修和状态。依据问题选 1～3 篇 content/ 正文，必要时补读先修知识。不要一次向上下文塞入整个库。

可运行 `python tools/search.py 关键词`。该搜索为关键词检索，不声称具备语义检索效果。正文编号与文件名稳定，标题可调整。

## ★★★★★ 怎么教

先判断提问者卡在概念、数学、代码还是任务背景。回答可按“核心直觉 → 最小算例 → 与先修的联系 → 常见误区 → 一个检查理解的问题”组织。已经要求直接解释时，不用连续追问拖延回答。

区分训练与推理、损失与指标、反向传播与参数更新、数学卷积与框架互相关、练习通过与真正掌握。默认学习者已掌握Python语言。数学不熟时解释符号与输入输出，不重复教Python语法。

## ★★★★★ 来源与边界

引用格式示例：`[math-dot，点积，§一次完整计算；参考：动手学深度学习·线性代数，配套书籍2023年，在线章节持续更新]`。

本库教学内容是模型整理的草稿，不声称直接转载教材，也不声称已经由教师审定。outline 节点只能作为待学方向。外部来源需确实读取后再给出其具体论点，不能凭链接标题编造引文。

## ★★★★ 跨产品用法

支持本地文件的 Agent 可直接读取目录。不支持本地文件访问的聊天产品，需要用户上传 `export/全部入门课程.md`，或从页面导出所需知识点。不同产品不一定自动识别 AGENTS.md，必要时在首条消息明确要求读取本指南。

本库不需要固定模型、专有数据库或向量存储；以后可在同一文件结构上加 MCP 或 RAG。外部模型仍可能需要联网。

来源：本项目教学与架构设计，2026-10-19。

## ★★★★ 第三轮选修实现范围

区分状态与观测、奖励与回报、V/Q与策略概率、terminated与truncated。PPO节点提供概念和裁剪目标检查，不是完整PPO训练器。DQN为one-hot状态小任务，不是像素输入Atari复现。

## ★★★★★ v0.3 默认范围

默认只教前两轮36课：数学与机器学习19课、深度学习/PyTorch与CNN17课，全部有正文。先读curriculum.json的mainPath与round。第三轮26节点独立，其中强化学习8篇正文，其余18框架；用户未要求时不要把第三轮当入门必修。全库44篇正文不等于覆盖整个ML/DL领域。

虚线/空心表示待编写，不等于不需要学；个人未开始表示有课但尚未学。CNN训练是合成横竖线任务，残差/冻结是机制检查，不是完整ResNet或预训练迁移。仍需教师审核。
