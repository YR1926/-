# 看见智能 · 学习图谱

本地数学 / 机器学习 / 深度学习知识库，v0.3.0，2026-10-19。默认已掌握 Python 语言基础。

## ★★★★★ 立即使用

**手机或电脑在线访问：[打开看见智能学习图谱](https://yr1926.github.io/-/)**。无需下载或解压；联网使用，进度保存在各自浏览器中。切换旧入口前先导出 JSON，再在网页中导入。部署方式见 [网页发布说明](docs/网页发布.md)。

**只想学习：直接下载仓库中的 [看见智能.html](看见智能.html)，双击打开，无需解压。** 在 GitHub 文件页点击“Download raw file”下载文件，不要保存 GitHub 的代码预览网页。文件内含全部课程、知识网络、年表、交互实验和可下载代码；请用 Edge 或 Chrome 打开，外部参考链接需联网，运行 PyTorch 仍需另装 torch。

需要维护或让 Agent 按文件检索：使用完整目录，双击 index.html 或 Windows 的“打开知识库.cmd”。两个入口来自同一份源文件。单文件版也可在“使用与维护”下载整课程 Markdown 给 Agent，或在知识点页面单独导出。

从旧入口换到单文件版前，请在“我的记录”导出备份，再在新入口导入；复制 HTML 不会带走浏览器中的进度。以后用同名新版替换旧 HTML，并保留 JSON 备份。详见 [单文件使用说明](docs/单文件使用.md)。

## ★★★★★ 年表与知识网络

二维年表采用从左到右的学习主轴，上下交错放置章节卡片。左右按钮、横向滚动、章节跳转和“定位下一课”都可用；点击卡片进入正文。轴表达建议学习顺序，不是算法发明年代，也不是全部先修关系。

知识网络默认显示三维星群：数学菱形、机器学习六边形、深度学习轨道节点、CNN叠层节点，配概念符号与外置文字标签。节点通过先修连线相连，选择后高亮邻接与关联，可旋转、缩放、暂停和双击阅读。二维学习年表保留为独立视图。默认主线与第三轮分别展示；完整先修与关联仍可在正文查看。

节点实线轮廓=有正文；虚线轮廓=正文待编写（二维年表对应实线卡/虚线卡），保留知识联系，并非“不用学”。“未开始/学习中/已阅读/练习通过”是个人学习状态，和内容有无分开。网络节点基础大小取决于当前范围的先修连接数量，同时随透视缩放；聚焦会放大，淡化表示当前焦点之外的节点。

## ★★★★★ 代码与边界

主线实现：`torch_ml.py`（回归、kNN、K-means、PCA）、`torch_foundations.py`（自动微分与MLP训练）、`cnn_basics.py`（小CNN完整训练/验证/测试）。知识点内可展开、下载同源代码。

CNN使用人工横竖线图像，不下载数据或权重。附有通道参数、投影残差、冻结梯度检查；不是原版LeNet、完整ResNet或预训练迁移学习复现。树模型页讲分裂与集成，不以Linear层冒充树算法。

第三轮保留表格Q、DQN、REINFORCE与PPO核心目标。PPO仅裁剪目标检查，不是完整训练器。所有合成任务结果不能推论到真实视觉性能。详见 [实践指南](examples/README.md)。

## ★★★★★ 进度与迁移

右上角“我的记录”导出JSON，换目录、电脑或浏览器后导入。侧栏只计前两轮36课；第三轮单独统计。保留稳定ID及旧Python节点的历史导出记录。正文版本更新会提示复习。浏览器缓存不等于可靠备份，两道选择题通过不等于掌握。
