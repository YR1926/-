# 机器学习在学什么：任务、数据与参数

## 你会解决什么问题

★★★★★ 普通程序由人写明规则；机器学习的一种常见做法是先规定模型形式，再利用样本调整参数。它不是没有规则，也不是把资料放进去就自然理解了一切。

## 四个必须分清的角色

- ★★★★★ 输入 x：模型可以观察的信息，例如一张图片的像素。
- ★★★★★ 标签 y：训练样本对应的目标，例如“猫”或一个真实计数。
- ★★★★★ 参数：模型内部可调整的量，例如权重 w 和偏置 b。
- ★★★★★ 预测：把输入送入当前模型得到的输出，可能与标签不同。

## 分类和回归

★★★★ 判断图片是猫还是狗，通常是分类；预测一个连续测量值，通常是回归。检测物体的位置还涉及坐标预测和类别判断，一个任务可能组合多种目标。

```python
def predict_size(x, weight, bias):
    return weight * x + bias

prediction = predict_size(3, 2, 1)
target = 8
error = prediction - target
print(prediction, error)  # 7 -1
```

这个模型暂时只是在按给定参数计算。只有定义误差怎样度量、参数怎样依据数据更新，才形成训练过程。

## 训练和推理

★★★★★ 训练阶段使用数据与目标调整参数；推理阶段用当前参数得到预测。训练损失降低不等于对新样本更可靠，所以需要独立评估。

请为“识别叶片是否有病斑”写出输入、标签、输出形式和可能的采样偏差。如果只拍摄某一块农田，模型可能利用背景而不是病斑本身。

## 常见误区

- ★★★★★ 监督学习是机器学习的一类，不是所有学习都需要同样形式的人工标签。
- ★★★★ 输入包含标签泄漏时，模型可能轻松得到高分，却无法在真实场景使用。
- ★★★★ “网络结构更深”不保证任务定义、数据质量或评估方法正确。

## 与计算机视觉的联系

★★★★★ CV 科研开始于明确任务和数据假设。先写清楚要预测什么、允许看到什么、怎样判断成功，再决定使用哪种网络。
