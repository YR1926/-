# PyTorch 张量、形状与设备

## 你会解决什么问题

★★★★★ 把数学运算落实到张量，掌握dtype、广播和设备一致性。

## 核心概念与计算

★★★★★ Tensor有shape、dtype、device。分类输入常是float32，CrossEntropyLoss的类别索引是long。CPU与GPU张量不能随意混算，模型和输入必须处于兼容设备。

★★★★ 广播从尾部轴比较，长度相同或其中一个为1可扩展。例如(N,1)减(N,)可能得到(N,N)，不会报错却改变了问题！检查loss之前的形状，比只看loss是否下降更可靠。`reshape`改变形状，`permute`交换轴的意义。

## 一次具体的推演

```python
import torch
x = torch.tensor([[1., 2.], [3., 4.]])
w = torch.tensor([[1.], [2.]])
y = x @ w
assert y.shape == (2, 1)
print(y.tolist())  # [[5.0], [11.0]]
```

## 常见误区

- ★★★★★ `(N,1)` 与 `(N,)` 可能广播成矩阵，需显式对齐。
- ★★★★ `.item()`取Python标量会离开张量计算图，不应用它继续构造待求导损失。

## 与计算机视觉的联系
