# 标量、向量与矩阵：给数据一个形状

## 你会解决什么问题

★★★★★ “图片是数据”到底是什么意思？我们要先知道数据由多少个数构成，以及这些数怎样排列。一个数是标量，一列按顺序排列的数可以表示向量，按行列排列的数可以表示矩阵。

## 从一个数到一张小图片

★★★★ 0.7 可以表示一个分数，是标量。[2, 5, 1] 可以表示一个三维向量，有三个分量。这里的“三维”表示三个数值坐标，不一定指现实世界的三维空间。

```python
image = [
    [0, 128, 255],
    [64, 128, 192],
]
print(len(image))     # 2 行
print(len(image[0]))  # 3 列
print(image[1][0])    # 第 2 行第 1 列：64
```

★★★★★ 这张单通道灰度图形状是 (2, 3)，约定先高后宽。0 表示黑，255 表示白，中间值表示不同亮度。这是常见 8 位图像表示，并非所有图像数据都用 0～255。

## 向量运算先逐项理解

★★★★ 两个长度相同的向量可逐项相加：[1, 2] + [3, 4] 在数学中得到 [4, 6]。乘以标量 2，得到 [2, 4]。但 Python 列表里的加号会连接列表，不做这种逐项加法。

```python
a = [1, 2]
b = [3, 4]
result = [a[0] + b[0], a[1] + b[1]]
print(result)  # [4, 6]
```

## 形状是计算的约束

★★★★★ 彩色图片可用高 H、宽 W、通道 C 三个轴组织，例如 (4, 5, 3)。深度学习还常把多张图片组成批次，使用 (N, C, H, W) 或 (N, H, W, C)。两种顺序都可能出现，必须看框架约定，不能只看四个数字猜含义。

## 常见误区

- ★★★★★ 张量的轴数与每个轴的长度不同；形状 (2, 3) 是二维结构，共有 6 个数。
- ★★★★ 同样有 6 个数的 (2, 3) 和 (3, 2) 结构不同；交换轴也不等同于随便重新排列。
- ★★★★ 本课只建立形状直觉；矩阵乘法有单独的匹配规则，后续再学。

## 与计算机视觉的联系

★★★★★ 大量模型错误来自输入通道数或形状不匹配。养成在数据进入模型前检查形状的习惯，是从初学者走向可靠实验的第一步。
