# 图像预处理与数据增强

## 你会解决什么问题

★★★★★ 匹配训练/验证流程，避免破坏标签语义。

## 核心概念与计算

预处理让输入符合模型约定，例如通道顺序、尺寸、dtype和数值范围。增强则在训练时随机制造合理变化。区分两者：验证和测试通常使用固定、可复现的预处理，不能每次随机裁剪后挑选好成绩。

归一化常用(x−μ)/σ。若自己估计μ与σ，只能使用训练集；若用预训练网络，应遵循其权重对应的预处理约定。增强应保持目标语义：左右翻转普通猫狗照片通常合理，翻转数字或医学图像可能改变含义；检测或分割中还要同步变换框或掩码。

## 一次具体的推演

像素[0,128,255]先除255，约得[0,0.502,1]，再用μ=0.5、σ=0.5得到[−1,0.004,1]。这个μ/σ只是教学设定，不能照搬到所有预训练模型。

原图和它的增强副本不能跨训练与测试划分，否则模型可能看到同一内容。先按原始样本或主体划分数据，再仅对训练分支施加随机增强。

## PyTorch 最小实现

```python
import torch
x = torch.tensor([0., 128., 255.]) / 255
normalized = (x - 0.5) / 0.5
image = torch.arange(12).reshape(1, 3, 4)
flipped = image.flip(-1)
assert flipped[0, 0, 0] == 3
print(normalized.tolist())
```

## 常见误区

- ★★★★ 不要对验证集反复随机增强并报告最优值。
- ★★★★ 归一化不是把所有数据都强制变成标准正态分布。
- ★★★★ 增强幅度过大会破坏标签含义，更多增强不必然更好。
